# Participant display

Open the link supplied by your experiment conductor. This view shows your
preferences, offers and score; it does not reveal the agent's true profile.

1. Read the instructions. When asked, arrange issues from most to least important,
   then rank each issue's values. Drag the rows or use the labeled up/down buttons;
   keyboard navigation is supported. Confirm when the preview matches your choices.
2. Wait for the conductor to start. The remaining time and turn come from the server.
3. Select a complete proposal under **Build your offer**. The proposed score updates
   before you send it. For resource allocation, select what **you keep**.
4. Use **Send offer**, or describe the proposal in **Your message**. Named pairs such
   as `Accommodation=Hotel; Destination=Paris` must use values in your displayed
   domain. For resource allocation you can also write, for example,
   `I want three apples, two bananas, zero oranges and four watermelons` if those
   quantities are available. Say what **you want to keep**, and include every issue.
   Counts accept digits or English words from zero to twenty. For larger counts,
   use digits; for complex wording, use the offer builder or `issue=value` pairs.
   Negative, fractional, approximate or partner-share requests need clarification.
   Incomplete/ambiguous text is a draft; it is not committed as an offer.
5. **Accept offer** (or `I agree` / `I accept`) accepts the current partner offer only.
   **Withdraw** ends the
   session without agreement. Follow the result, questionnaire and break screens.

If speech is configured, **Capture speech draft** produces editable text. Check it
before sending. Optional self-report is labeled as your rating, independently of
any configured sensor. Ask the conductor if a device fails; an uncertain delivery
is not automatically replayed.

Refreshing reconnects to the same record. Opening the next session clears its
current history while preserving the previous session for the conductor. This
software guide does not replace your study's participant information and consent.
