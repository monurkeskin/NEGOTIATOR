# Contributor instructions

Use Python 3.11+ and this repository's uv lock and environment. Keep domain objects
independent of UI and device SDKs. Session state and durable events must describe
the same committed actions. Add a failing behavioral test before fixing a defect.
Run focused tests while developing, then the affected integration tests. Scientific
claims require a cited source or a recorded run; synthetic examples are not human
study results. Never commit participant records, credentials or device recordings.
Preserve source notices and asset hashes when changing adapted components.
